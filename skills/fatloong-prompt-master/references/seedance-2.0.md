# Seedance 2.0 提示词方言

只在目标模型明确为 **Seedance 2.0** 时使用。

---

## 一、硬参数

| 维度 | 规格 |
|---|---|
| 单次时长 | 4–15 秒 |
| 正文长度 | 中文建议 ≤500 字 |
| 图片输入 | ≤9 张，单张 <30MB |
| 视频输入 | ≤3 段，每段 2–15 秒 |
| 音频输入 | ≤3 段，每段 2–15 秒 |
| 混合上限 | 图片 + 视频 + 音频 ≤12 个 |
| 音频单独输入 | **不允许**，至少配 1 图或 1 视频 |
| 写实真人脸素材 | **不支持上传**，平台自动拦截 |

时长不在 4–15 秒区间的镜头，回导演阶段拆或补，**不在这里截断**。

---

## 二、三种起点互斥

官方把以下三种列为互斥场景，**同一次生成只能选一种**：

| 模式 | 素材 | 适用 |
|---|---|---|
| **首帧** | 1 张图作为开场 | 常规图生视频，最常用 |
| **首尾帧** | 2 张图，分别标首帧、尾帧 | 终点状态必须精确 |
| **全模态参考** | 图 0–9 + 视频 0–3 + 音频 0–3 | 需要人物图 + 地点图 + 首帧同时控制 |

**关键取舍：**

- 只要“开场严格对上某张图” → 走首帧，人物和地点只能靠这张图本身承载
- 要“首帧 + 人物参考 + 地点参考” → 只能走全模态参考，正文写 `@图片1 作为首帧`
- 不要把首帧模式的图和全模态参考的图混在同一次请求里

## 三、正文结构

```
[主体] + [动作细节] + [场景] + [光色] + [运镜] + [视觉形态] + [约束]
```

**具体可见事实优先。** 质量词只保留必要项，不堆“电影感、史诗、8K”。

### 单镜

按动作先后写，一句话能说清就不要拆。

### 一次生成含多个镜头

用镜头序号，**不写时间戳**：

```
镜头1：[谁、在哪、做什么、镜头怎么动]。
镜头2：[...]。
镜头3：[...]。
```

官方说明 2.0 响应镜头序号、**不响应时间戳**。秒数只作为你的内部预算，正文用动作顺序和相对停顿表达。

> 三次小样本里，镜头切点并没有按两镜均分。需要精确边界时，改用独立生成再剪辑。

## 四、站位与视线

这是 2.0 最容易翻车的地方。

### 按机位写前后关系，不只写关系

| 写法 | 结果 |
|---|---|
| 走到桌前，隔着桌子与他面对面 | 九次小样本都被放成同侧 |
| 机位在桌前，她走进前景、背对镜头停在桌子这一边，桌子在她和他之间 | 三次都对 |

### 可以放心写的

- 画面左右：`男人在画面左侧`、`她从右侧门口进来`
- 视线对象：`看着坐在对面的他`
- 画外人物：`对方在画外，不入画`

### 必须避免的

- 只写“两人面对面”不写机位
- 只写“他在她身后”不写前后景
- 让画外人物被模型自行补进画面

## 五、对白与声音

| 类型 | 格式 | 示例 |
|---|---|---|
| 对白 | `{角色用中文说：“逐字台词”}` | `{林雪用中文说：“你走吧。”}` |
| 音效 | `<声音>` | `<门锁咔哒一声>` |
| 音乐 | `（音乐）` | `（低频弦乐持续，压迫感）` |
| 字幕 | 仅明确开启时用 `【字幕】` | 默认禁用 |

**五条纪律：**

1. 每个可辨对白事件都必须整体写进花括号，不能只留普通引号
2. 同一句对白在单条正文只出现一次
3. 中文对白不写语言前缀；非中文对白才写，如 `{林雪用日语说：“行こう。”}`
4. 同一段对白只用一种口语语言，不在台词前加外语暖场
5. 默认禁字幕时明写 `全程保持无字幕，不生成对白文字叠加`，正文不出现任何 `【】`

**字幕开启条件：** 只有用户明确要求字幕时才用 `【字幕】`，并写清位置（底部居中）、时机与内容。
用户没提，一律按禁用处理。

## 六、参考图挂载

最多 9 张，**上限不是目标**。每张图都要在本镜有具体职责。

| 职责 | 是否必须挂图 |
|---|---|
| 起始帧 | 是 |
| 正在说话 / 动作的人物身份 | 是 |
| 必须认得出的道具 | 是 |
| 地点 | 是 |
| 定调图、氛围参考 | 可选 |

实测：一组递文件夹的镜头，挂 7 张与挂 3 张，身份和画面没有差别；
但没挂文件夹的那组，3 次里 2 次文件夹变成了夹板。

**结论：必须认得出的道具要挂图，不能只靠文字。**

超过 9 张时的取舍顺序：
起始帧 → 说话人物 → 关键道具 → 地点 → 其他人物 → 氛围参考

## 六b、什么时候补角色串

图生视频时，静态外观由首帧承担。但以下情况必须补一句 CHR 串：

| 情况 | 处理 |
|---|---|
| 首帧里主角占画面 ≥1/3 | 不补 |
| 首帧里主角 <1/3 | 补，20–40 字 |
| 主角被前景遮挡 | 补 |
| 主角不在首帧画面内 | 补 |
| 镜头内切到主角近景 | 补 |

补的时候用完整 CHR 串，不要简写成“主角”或“他”。
否则模型会重新生成一个“差不多的人”，一致性直接崩。

---

## 七、正文长度

建议 150–500 字。短镜（≤3 秒）可更短，不必凑字数。
超过 500 字时**先删不进画面的环境铺陈**，不要为了字数删身份锚点。

一组实测（同一镜头分别约 100、460、800 字）：
后段细节并没有因为长而明显丢失，但 800 字那组把正文里随手提到的猫、出租车都画了出来。

**控制长度的正确方法：只写这一镜需要被看见的东西，不靠删字凑数。**

## 八、完整示例

```
@图片1 作为首帧。中景，平视，男人在画面左侧，女人在画面右侧，两人隔着折叠饭桌。
男人把信封推到桌子中间，手指在信封上停了一秒才收回，下颌收紧。
女人低头看信封，没有伸手，视线从信封移到男人脸上。
<信封摩擦桌面的沙沙声>。
{男人用中文说：“拿着。”}
{女人用中文说：“你早就想好了？”}
镜头缓慢推近至中近景，背景窗帘轻微晃动。
全程保持无字幕，不生成对白文字叠加。
禁止：任何文字、字幕、LOGO、水印、多余手指、五官漂移。
```

字数约 210 字，落在建议区间内。

## 九、常见错误

| 错误 | 后果 | 修正 |
|---|---|---|
| 写时间戳 `0-3秒` | 2.0 不响应，白写 | 改成镜头序号 + 动作顺序 |
| 首帧和人物参考混用 | 请求被判互斥 | 选首帧或全模态参考，二选一 |
| 正文超过 800 字 | 模型只抓重点，乱加元素 | 删环境铺陈，保留锚点 |
| 只写“两人面对面” | 站位被放成同侧 | 按机位写前后景 |
| 对白用普通引号 | 可能不生成语音 | 改成花括号格式 |
| 挂 9 张图但职责重复 | 浪费额度，还增加干扰 | 每张写清职责，重复的删掉 |
