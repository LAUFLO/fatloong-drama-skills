# 关键帧图片提示词规范

本文件解决第三步：把分镜的一瞬间写成可直接出图的中文提示词。

---

## 一、先筛后写

不是每个镜头都值得出一张图。先做筛选，结果交用户确认。

### 必出

| 条件 | 原因 |
|---|---|
| 开场钩子镜 | 第一印象，决定观众是否留下 |
| 转折 / 反转 / payoff 镜 | 视觉信息最重，错不起 |
| 新场景首次出现 | 建立空间锚点 |
| 新角色首次出现 | 建立身份锚点 |
| 复杂构图 / 多角色互动 / 大场面 | 纯文字难以稳定复现 |
| 视觉密度最高的镜 | 细节多，需要图来锁 |

### 可复用

| 情况 | 复用方式 |
|---|---|
| 同场景同机位连续镜头 | 共用一张首帧 |
| 同角色正反打 | 共用一张角色图承担一致性 |
| 同一动作的分解镜 | 用动作终点帧接下一镜起点 |

### 可跳过

| 情况 | 理由 |
|---|---|
| 纯字幕 / 黑屏 / 纯色背景 | 无视觉内容 |
| 单纯过渡空镜 | 生成成本高于收益 |
| 时长不足 2 秒的插入镜 | 一闪而过，观众读不到细节 |

### 筛选输出格式

```markdown
| 场景 | 镜号 | 出图 | 理由 |
|---|---|---|---|
| 场景1 | 001 | 必出 | 开场钩子 |
| 场景1 | 002-004 | 复用 001 | 同机位连续 |
| 场景1 | 005 | 跳过 | 纯字幕 |
```

**默认不全出。** 预估出图量控制在总镜数的 40%–60%。

## 二、两类图片

| 类型 | 用途 | 画幅 | 数量 |
|---|---|---|---|
| **角色卡** | 校准角色一致性，供后续 `@图片N` 引用 | 9:16 竖版 | 每个角色 1 张 |
| **关键帧** | 每镜的首帧，图生视频的起点 | 与成片一致 | 按筛选结果 |

角色卡在**第三步开头**决定要不要出，先于关键帧筛选。

角色卡不是每部片都必须。角色少于 3 个、且全片靠文字锚定能稳住时，可跳过。
目标为 Seedance 2.0 且题材写实时也必须跳过——平台不收真人脸，出了也挂不上。

---

## 三、关键帧结构

一段连续文本，顺序固定，用句号分隔：

```
[画幅比]。[风格锚定串]，[景别 + 机位 + 视觉重心]。
[角色锚定串] + [定格姿态与表情]。
[场景锚定串] + [本镜特有环境细节]。
[光影：主光方向 + 补光 + 轮廓光 + 色温]。
[色调与质感]。
[负面词表]
```

### 逐段要求

| 段 | 必须包含 | 禁止 |
|---|---|---|
| 画幅比 | `16:9` / `9:16` / `1:1` / `2.39:1` | 省略 |
| 风格 | 完整风格锚定串 | 改写、缩写 |
| 角色 | 完整角色锚定串 + 此刻姿态 | 只写角色名 |
| 场景 | 完整场景锚定串 + 本镜细节 | 写“同上” |
| 光影 | 方向 + 色温 + 质感 | 写“光线好” |
| 质感 | 颗粒、锐度、材质 | 堆砌英文标签 |
| 负面 | 完整负面词表 | 只写“不要崩” |

## 四、角色卡结构

一段连续文本，顺序固定：

```
9:16竖版构图。[风格锚定串]。角色设定图，[正面/四分之三侧/侧面]，[半身/全身]，纯色背景，角色居中。
[面部：脸型 + 眼型 + 眼神 + 眉形 + 鼻型 + 唇形唇色 + 肤色肤质 + 表情]。
[发型：发色 + 长度 + 造型 + 特殊状态]。
[头饰/装饰：类型 + 材质 + 位置]。
[服装从上到下：领口 + 材质 + 颜色 + 新旧 + 污渍 + 垂坠状态]。
[道具：外观 + 材质 + 持握方式]。
[体态气质：身材 + 姿态]。
[光影：主光 + 补光 + 色调]。
[画质要求]。
[负面词表]
```

### 五条关键原则

1. 东方题材必须写“东方面孔、中式五官”
2. 服装新旧忠实还原，破旧写破旧，**严禁美化**
3. 宁可少写一个细节，不编造一个错误细节
4. 唇色、领口开合、材质新旧最容易写错，写完逐项对分镜
5. 头饰、犄角、面纱这类装饰是辨识度核心，不能漏

### 六种常见错误

| 错误 | 后果 |
|---|---|
| 唇色降级（深红写成淡粉） | 角色气质整体偏移 |
| 领口开合写反（露背写成高领） | 后续所有镜头衣服都不对 |
| 材质美化（破旧写成崭新） | 人物阶级感消失 |
| 漏掉污渍磨损 | 画面变“干净”，失去生活感 |
| 漏掉头饰 | 角色辨识度大幅下降 |
| 编造不存在的细节 | 与分镜脱节，返工 |

## 五、完整示例

```

面部：鹅蛋脸，细长单眼皮，眼尾微下垂，平直眉，鼻梁挺直，薄唇裸色，偏黄肤色带真实毛孔，东方面孔，视线平视略显疲惫。
发型：黑色短发，长度及耳，鬓角有少量白发。
头饰：无。
服装：深灰棉质圆领T恤，领口松垮变形，左胸有一块洗不掉的暗色油渍；外搭藏青工装夹克，袖口磨损起毛，拉链只拉到一半。
道具：右手夹着一根未点燃的烟。
体态：肩宽背厚，站姿略微前倾，重心偏左脚。

超精细写实人像，皮肤纹理可见，35mm胶片颗粒。
禁止：任何文字、字幕、LOGO、水印、多余背景元素、五官变形、多余手指。
```

## 六、平台差异

| 维度 | NanoBanana | 即梦图片生成 |
|---|---|---|
| 写实人脸 | 可以 | **不可**，平台拦截 |
| 语法 | 中文自然语言 | 中文自然语言 |
| 画幅 | 开头写明 | 开头写明 |
| 画质标签 | 中文描述质感 | 可用“8K、超精细” |

### 通用禁止项

- Midjourney 语法：`--ar 3:4 --v 6 --style raw`
- SD / NovelAI 语法：`masterpiece, best quality, 1girl`
- 堆砌英文画质标签：`8K, ultra detailed, cinematic lighting`

**统一用中文描述画面内容和质感。** 需要英文术语时只保留模型专有名词。

## 七、第三步自检清单

- [ ] 出图筛选表是否先给用户确认，而不是直接全出？
- [ ] 每条是否以画幅比开头？
- [ ] 风格、角色、场景三条锚定串是否逐字复制？
- [ ] 定格动作是否是“能截成照片”的瞬间？
- [ ] 光影是否写到了方向 + 色温？
- [ ] 角色卡的唇色、领口、材质新旧是否与分镜一致？
- [ ] 是否没有使用 MJ / SD 语法？
- [ ] 每条是否以负面词表结尾？
- [ ] 跳过的镜头是否都有明确理由？
