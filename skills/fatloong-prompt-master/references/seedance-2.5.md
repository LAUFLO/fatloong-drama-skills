# Seedance 2.5 提示词方言

只在目标模型明确为 **Seedance 2.5** 时使用。

---

## 一、硬参数

| 维度 | 规格 |
|---|---|
| 单次时长 | 4–30 秒 |
| 多镜容器 | 可做 30 秒长叙事 |
| 时间控制 | 支持整数秒时间戳 |
| 任务类型 | reference / edit / extend |
| 音频参考 | 支持 `@音频1` 音色参考 |
| 语言 | 中文自然指令 |
| 素材绑定 | `@图片N`、`@视频N`、`@音频N` |

2.5 沿用 2.0 的中文自然指令和 @ 引用，但**不能直接套 2.0**。
它多了 30 秒时长、时间戳、编辑与延长三类任务。

---

## 二、三类任务：先定任务，再写正文

提示词意图必须与任务类型一致，否则会被判任务类型不匹配。

| 任务 | 用途 | 正文怎么写 | 附加要求 |
|---|---|---|---|
| **reference** | 基于素材生成新视频 | “参考 @视频1 的运镜”“@图片1 的人物形象” | 说明保留和借用什么 |
| **edit** | 直接修改已有视频 | “保留 A、B，只修改 C”，点名 `@视频1` | `ratio: adaptive`，`duration: -1` |
| **extend** | 在已有视频后续写 | “在 @视频1 的基础上续写 N 秒” | `ratio: adaptive` |

**不要写成“参考它生成另一段”再标 edit，也不要反过来。**
任务类型是创作选择，不能靠关键词猜。

### 输出时单列一行

在 `MOTION-` 条目里加：

```
- 任务类型：reference
```

只对 2.5 写这一行。目标不是 2.5 时不要出现。

---

## 三、时间戳容器

多镜或长叙事按时间段写，**不重叠、不留无意空档**，最后终点等于总时长：

```
镜头 1 [0:00–0:03]：[画面 + 动作 + 运镜 + 声音]
镜头 2 [0:03–0:07]：[...]
镜头 3 [0:07–0:12]：[...]
```

### 三条规则

1. 时间戳是**预算**，不是执行保证。生成仍有偏差，不能当精确剪辑点
2. 单镜内部先写清动作先后与触发，散文式的秒数不保证精确落点
3. 对白音节同步不能靠时间戳保证，要按发声窗口复核

### 短单镜不用时间戳

单镜按自然顺序写：

```
主体 + 动作 + 场景 + 光色 + 运镜 + 风格 + 约束
```

## 四、素材绑定

每次使用素材时**重复绑定具体职责**，不要只在开头列清单。

| 写法 | 是否正确 |
|---|---|
| `人物 @图片1` | 正确 |
| `@视频1 的表演节奏` | 正确 |
| `参考 @视频1 的运镜，@图片1 的人物形象` | 正确 |
| 开头写“参考图：图片1”，正文不再提 | 错误 |

**原则：不让一个素材顺手控制身份、动作、构图等所有维度。** 每张图只控制它该控制的。

---

## 五、首尾帧

接口提供 `first_frame` 与 `last_frame` 两个位置，**各自只收一张**。

| 情况 | 处理 |
|---|---|
| 终点状态重要 | 增加尾帧约束，同时仍要检查中间动作与节奏 |
| 未提供尾帧 | 在正文中写清终点状态 |
| 开场构图要锁死 | 用 `first_frame`，不要只在正文写“@图片1 是开场画面” |

两个帧位各占一个图片序号，`@图片N` 按素材出现顺序连续编号，**不跳过**。

**混用警示：** 首尾帧与其他参考能否组合，不同接口版本结果不同。
素材角色共用一个 `content` 数组，不能证明任意组合都会被接受。
先用最小组合试一次，确认后再批量。

> 实测：把上一段真实尾帧挂成参考图（而非 `last_frame`），3 次开场与它的相似度只有 0.09–0.46。
> 要锁开场，就老老实实用首帧位。

## 六、声音

格式与 2.0 一致：

| 类型 | 格式 |
|---|---|
| 对白 | `{角色用中文说：“逐字台词”}` |
| 音效 | `<声音>` |
| 音乐 | `（音乐）` |
| 字幕 | 默认禁用，明写 `全程无字幕、无对白文字叠加` |

**语言标注：** 中文对白不写前缀；非中文对白写清语言，如 `{林雪用日语说：“行こう。”}`。
同一段对白只用一种口语语言。

**字幕开启条件：** 用户明确要求时才用 `【字幕】`，写清位置、时机与内容；没提按禁用处理。

### 音色参考

任务支持 `reference_audio` 时，可写：

```
沈一舟说话时音色参考 @音频1
```

实测：绑一段该角色另一句话的合成做参考，青年角色 6 镜里 5 镜明显靠近，中年角色 3 镜没有变化。
**绑定只是提高命中，逐镜回听不能省。**

---

## 七、与 2.0 的差异对照

| 维度 | 2.0 | 2.5 |
|---|---|---|
| 时长 | 4–15 秒 | 4–30 秒 |
| 多镜 | 用镜头序号 | 可用时间戳容器 |
| 起点 | 首帧 / 首尾帧 / 全模态参考，三选一 | first_frame / last_frame 独立使用；与其他参考能否混用，必须核对目标接口 |
| 任务类型 | 无 | reference / edit / extend，必须单列 |
| 音频参考 | 无独立音频参考 | `@音频1` 音色参考 |
| 视频续接 | 向后延长 `@视频1` | extend 任务 + `ratio: adaptive` |
| 正文长度 | ≤500 字 | 单镜同样克制，30 秒容器才展开 |

## 八、完整示例

```
@图片1 作为首帧，@图片2 的人物形象。
镜头 1 [0:00–0:04]：中景，平视，男人在画面左侧把信封推到桌中，手指停在信封上一秒。
<信封摩擦桌面的沙沙声>。
镜头 2 [0:04–0:08]：女人低头看信封，没有伸手，视线从信封移到男人脸上。
{男人用中文说：“拿着。”}
镜头 3 [0:08–0:12]：镜头缓慢推近至中近景，女人嘴角动了一下，最终没有开口。
{女人用中文说：“你早就想好了？”}
<低频弦乐渐入>。
全程无字幕、无对白文字叠加。
禁止：任何文字、字幕、LOGO、水印、多余手指、五官漂移。
```

时间戳连续，终点 12 秒等于总时长。

## 九、常见错误

| 错误 | 后果 | 修正 |
|---|---|---|
| 把 2.0 的“三种起点互斥”套到 2.5 | 白白放弃组合能力 | 按 2.5 维度组合，但逐一核对接口 |
| 写了时间戳却没对齐终点 | 末尾空档或截断 | 最后一段终点 = 总时长 |
| edit 任务标成 reference | 被判任务类型不匹配 | 任务类型单列，正文同步改 |
| 只在开头列素材清单 | 模型不知道该参考什么 | 每次提及都重复绑定职责 |
| 用尾帧参考图代替 `last_frame` | 开场相似度极低 | 要锁开场就用首帧位 |
| 30 秒容器硬塞多段独立场景 | 生成质量下降 | 独立场景拆成多次生成 |
