# 质检清单与返修

两段检查：**输出前**查提示词本身，**生成后**查画面结果。

---

## 一、输出前自检（每批必做）

### 1. 一致性

- [ ] STY 串全文逐字一致
- [ ] 每个 CHR 串逐字一致，没有同义改写
- [ ] 每个 LOC 串逐字一致，没有“同上”
- [ ] 负面词表全文一致
- [ ] 角色卡在第三步开头已决定，跳过的理由已写明

### 2. 可生成性

- [ ] 每条都是可截帧的瞬间（IMG）或可描述的变化（MOTION）
- [ ] 没有心理描写、没有括号暗示
- [ ] 没有分镜之外的元素
- [ ] 动作量与该镜时长匹配

### 3. 篇幅

- [ ] 2.0 单镜 150–500 字，短镜没有为凑字数注水
- [ ] 2.5 单镜 150–500 字，30 秒容器才展开
- [ ] 超长时删的是环境铺陈，不是锚点

### 4. 声音

- [ ] 对白逐字照抄分镜，格式为花括号
- [ ] 音效用 `<>`，音乐用 `（）`
- [ ] 中文对白无语言前缀，非中文对白已标注语言
- [ ] 默认禁字幕已明写；用户要求字幕时，位置与时机已写清
- [ ] 同一句对白没有重复出现

### 5. 模型适配

- [ ] 2.0 没有写时间戳
- [ ] 2.0 的素材只有 @图片N，没有残留任务类型行
- [ ] 2.5 写了任务类型，时间戳连续
- [ ] 2.5 的 edit/extend 素材写的是 @视频N，没有误写成图生视频
- [ ] 时长在各自区间内
- [ ] 每个生成单元在 4 秒以上
- [ ] 单个单元内的分镜镜头数 ≤4
- [ ] 单元表与分镜镜号一一对应，无遗漏
- [ ] 没有把 2.0 的互斥规则套到 2.5

### 6. 平台合规

- [ ] 图片生成平台已确认（NanoBanana / 即梦图片）
- [ ] 没有上传写实真人脸素材
- [ ] 2.0 + 写实题材时，没有把写实角色图当参考素材
- [ ] 没有触发审核的敏感描述
- [ ] 品牌 LOGO、影视 IP 形象已规避

## 二、生成后诊断

| 症状 | 最可能原因 | 修法 |
|---|---|---|
| **换脸 / 五官漂移** | 近景配大幅环绕；锚定串被改写 | 删旋转运动；逐字恢复 CHR 串 |
| **服装变了** | 服装描述被压缩；没挂角色图 | 补全服装层级；挂角色卡 |
| **场景变了** | 场景串被简写；正文提了无关地点 | 恢复 LOC 全串；删无关地名 |
| **多手指 / 肢体畸形** | 手部动作复杂、近景、遮挡多 | 简化手部动作；避免手指特写；加负面词 |
| **动作没发生** | 动作写在静态描述里；一镜塞太多动作 | 改成明确的起止状态；拆动作 |
| **动作过快 / 过慢** | 时长与动作量不匹配 | 回导演阶段调时长，或在正文写节奏 |
| **对白没声音** | 用了普通引号；台词散落在括号外 | 改成花括号格式 |
| **字幕乱入** | 没明写禁字幕；正文出现 `【】` | 加“全程无字幕”；删字幕指令 |
| **画面糊 / 过曝** | 画质词堆砌；光影描述冲突 | 删质量词；统一光源方向 |
| **风格漂移** | 每条风格描述不同 | 恢复 STY 串，逐字复制 |
| **多了正文没写的元素** | 正文提到了但不该入画的对象 | 删掉该描述；明确“画外不入画” |
| **镜头切点不对** | 2.0 写了时间戳 | 改用镜头序号；或独立生成再剪 |

## 三、崩脸陷阱

### 高危组合

```
近景 Z1–Z3  +  X 轴大幅环绕 / 旋转  =  崩脸
```

近景时人脸占据画面主体，模型没有足够信息补全侧后方，一转就变形。

### 运动上限

| 规则 | 说明 |
|---|---|
| 每镜最多两个轴向运动 | 推拉 + 横移可以；推拉 + 环绕 + 升降不行 |
| 近景只用单轴 | Z3 及更近，只做推、拉或固定 |
| 环绕留给中景以上 | Z5 及更远才用 Orbit |
| 旋转只做小角度 | 超过 45° 必须离开近景区 |

### 安全组合速查

| 景别 | 可用运动 |
|---|---|
| Z1–Z3 近景 / 特写 | 固定、缓慢推近、缓慢拉远、轻微摇 |
| Z4–Z6 中近景 / 中景 | 推拉、横移、跟拍、小角度环绕 |
| Z7–Z9 全景 / 远景 | 升降、环绕、摇臂、大范围移动 |

## 四、篇幅超标怎么删

按顺序删，删到够为止：

1. **不进画面的环境铺陈**——“远处有城市轮廓和晚霞”如果画面根本带不到，删
2. **修饰形容词**——“极其、非常、十分、完美、震撼”
3. **重复信息**——锚定串已经写过的不再复述
4. **次要背景人物**——除非剧情需要，否则不写

### 永不删

- 角色身份锚点
- 逐字对白
- 连续性锁面（服装、道具、伤口位置）
- 负面词表

## 五、平台审核规避

| 风险项 | 处理 |
|---|---|
| 写实真人脸素材上传 | 平台直接拦截，改用非写实或纯文字锚定 |
| 泳装 / 暴露 | 用 `身形、腰线、轮廓` 替代敏感部位词，加“得体、自信”护栏 |
| 暴力 / 血腥 | 用结果暗示替代过程直写，避免伤口特写 |
| 品牌 LOGO / 影视 IP | 全部去掉，用中性描述替代 |
| 真实公众人物 | 不写姓名、不写可识别特征 |

审核被拒时，**一次只改一个变量**，否则无法定位是哪句触发的。

---

## 六、返修优先级

### 一次只改一个变量

按影响面排序，先改最可能的那一个：

1. 锚定串是否被改写
2. 运动是否超限
3. 篇幅是否超标
4. 声音格式是否正确
5. 模型参数是否用错

### 三振规则

同一个镜头、同一个问题，连续三次修改仍不解决：

**停止在提示词层返工，回上游。**

| 问题 | 回哪 |
|---|---|
| 动作在时长内做不完 | 回导演，拆镜或加时长 |
| 画面信息不足以生成 | 回导演，补画面内容 |
| 角色设定本身矛盾 | 回导演定调，统一人物设定 |
| 分镜镜头语言无法用模型实现 | 回导演，换镜头方案 |

继续在提示词里打补丁，只会让正文越来越长、越来越糊。
