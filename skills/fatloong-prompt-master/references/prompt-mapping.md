# 九列表 → 提示词字段映射

本文件解决一个问题：导演给的九列分镜表，每一列到底怎么变成提示词。

---

## 一、总原则

九列分镜表是为**拍摄**设计的，提示词是为**生成**设计的。
列与列之间不是一一对应，而是分成四类处理：

| 处理方式 | 涉及列 | 说明 |
|---|---|---|
| **直接翻译** | 景别、摄影角度、备注（运镜） | 换成模型听得懂的术语 |
| **补写具体化** | 画面内容、场景 | 补光影、材质、空间结构 |
| **仅用于视频** | 声音、时长 | 图片提示词完全不写 |
| **不进入提示词** | 叙事目的 | 只作为你的判断依据 |

---

## 二、逐列映射表

| 分镜列 | IMG 图片提示词 | MOTION 视频提示词 | 规则 |
|---|---|---|---|
| 镜号 | `IMG-007` | `MOTION-007` | 前缀 + 三位镜号 |
| 时长 | 不写 | 写模型时长参数 | 必须落在模型区间 |
| 摄影角度 | 写，映射 Y 轴 | 只写机位变化 | 见第四节 |
| 景别 | 写，映射 Z 轴 | 只写景别变化 | 见第三节 |
| 画面内容 | 改写为定格瞬间 | 改写为变化过程 | 见第五节 |
| 场景 | 场景锚定串 + 本镜细节 | 不重复，只写环境动态 | 见第六节 |
| 声音 | **不写** | 完整声音时间线 | 见第七节 |
| 备注 | 特效、构图、色彩 | 运镜、速度、焦点 | 见第八节 |
| 叙事目的 | **不写** | **不写** | 见第九节 |

---

## 三、景别映射到 Z 轴

| 分镜用词 | Z 编码 | 英文 | 提示词写法 |
|---|---|---|---|
| 大远景 / 大全景 | Z9 | ELS | 大远景，城市/山脉尺度 |
| 远景 | Z8 | LS | 远景，人小景大 |
| 全景 | Z7 | FS | 全景，完整人体与环境 |
| 中远景 | Z6 | MLS | 四分之三身，膝盖附近 |
| 中景 | Z5 | MS | 中景，腰部以上 |
| 中近景 | Z4 | MCU | 中近景，胸口以上 |
| 近景 | Z3 | CU | 近景，完整面部 |
| 特写 | Z2 | BCU | 特写，眼睛/嘴/手 |
| 大特写 / 微距 | Z1 | ECU | 大特写，瞳孔/指纹/伤口 |

**景别变化镜头**（如“特写转全景”）：
- IMG 只写**起点景别**（定格在第一帧）
- MOTION 写 `从特写拉远到全景`

**注意：** Z1–Z3 属于近景区，配大幅环绕或旋转会崩脸，见 `qc-checklist.md`。

## 四、摄影角度映射到 Y 轴

| 分镜用词 | Y 编码 | 提示词写法 | 心理效果 |
|---|---|---|---|
| 极高俯拍 | Y7 | 垂直顶视，鸟瞰 | 上帝视角、地图感 |
| 俯拍 | Y6 | 高角度俯拍 | 弱化、被困、孤独 |
| 微俯拍 | Y5 | 轻微俯视 | 客观观察 |
| 平视 / 平拍 | Y4 | 平视 | 平等、日常，默认 |
| 仰拍 | Y2 | 低角度仰拍 | 强大、压迫 |
| 低机位 | Y1–Y2 | 贴近地面的低机位 | 超现实、巨物感 |

### X 轴方位：分镜没写时必须补

分镜表只写了俯仰，没写环绕方位。写提示词时按叙事需要补一个：

| X 编码 | 方位 | 何时用 |
|---|---|---|
| X1 | 正面 | 独白、播报、打破第四面墙 |
| X2 | 四分之三侧 | **默认推荐**，最立体自然 |
| X3 | 侧面 | 对峙、并行、剪影 |
| X4 | 背面 | 悬念、跟随进入 |

**规则：** 同一场景的连续镜头，X 轴不要连续三次相同，否则剪出来像机位没动。

## 五、画面内容怎么改写

### 5a. 图片：动作句 → 定格句

| 分镜原句 | IMG 改写 |
|---|---|
| 老王推开门走进来 | 老王右手推门，门开到一半，身体前倾，左脚刚跨过门槛 |
| 她坐在窗边发呆 | 她侧坐在窗边木椅上，右手托腮，视线落在窗外，嘴唇微张 |
| 人群四散奔逃 | 人群向画面两侧散开，最近一人回头，嘴张开，外套下摆扬起 |

判断标准：**能截成一张照片。**

### 5b. 视频：静态描述 → 变化过程

| 分镜原句 | MOTION 改写 |
|---|---|
| 老王推开门走进来 | 门从半开被推到全开，老王跨过门槛，重心前移，最后停在画面中央 |
| 她坐在窗边发呆 | 她保持坐姿，视线从窗外缓慢收回，眼皮下垂，肩膀下沉 |
| 人群四散奔逃 | 人群从中心向两侧扩散，镜头轻微后拉，最近一人跑出画外 |

判断标准：**能说清从哪一帧变到哪一帧。**

### 5c. 情绪词必须落到可见表现

| 不可拍 | 可拍 |
|---|---|
| 他很紧张 | 他喉结上下滚动，手指在裤缝上反复摩擦 |
| 她很失落 | 她肩膀塌下去，视线落到地面，呼吸变浅 |
| 气氛压抑 | 画面留白占三分之二，人物贴边，环境音只剩低频嗡鸣 |

## 六、场景怎么处理

| 情况 | 处理 |
|---|---|
| 场景首次出现 | 写完整场景锚定串 |
| 同场景后续镜头 | 只写本镜机位与局部细节，不重复全串 |
| 同场景但换了区域 | 在锚定串基础上补新区域，不换串 |
| 换场 | 必须换串，不允许“同上” |
| 抽象 / 纯色背景 | 写“纯黑背景”“纯白无边界空间”，不套实景串 |

## 七、声音 → 视频提示词

| 分镜「声音」列 | MOTION 写法 |
|---|---|
| 对白 | `{角色用中文说：“逐字台词”}` |
| 旁白 / 画外音 | `{旁白用中文说：“逐字台词”}`，并注明画外 |
| 音效 | `<具体声音>`，如 `<雨点打在铁皮棚上>` |
| 配乐 | `（音乐）风格 + 功能`，如 `（低沉弦乐渐入，压迫感）` |
| 静默 | 明写 `全程静默，无任何环境音与配乐` |

**三条纪律：**
1. 对白逐字照抄，不改写、不补语气词
2. 同一句对白在单条正文只出现一次
3. 默认禁字幕时明写“全程无字幕，不生成对白文字叠加”

## 八、备注 → 技术参数

| 备注内容 | IMG | MOTION |
|---|---|---|
| 镜头运动 | 写起点机位 | 写完整运动轨迹 |
| 特效 | 写特效的静止形态 | 写特效的变化过程 |
| 字幕 | 不写（字幕后期加） | 不写 |
| 焦点转换 | 写焦点落在谁身上 | 写 `焦点从 A 拉到 B` |
| 慢动作 / 加速 | 不写 | 写 `120fps 慢动作` / `加速` |
| 色彩 / 滤镜 | 写色调 | 不重复 |
| 构图 | 写构图关系 | 只写构图变化 |

## 九、叙事目的怎么用

叙事目的**一个字都不进提示词**，但它决定四件事：

| 用途 | 怎么用 |
|---|---|
| 决定强调对象 | “建立空间” → 环境占比大；“情绪转折” → 面部占比大 |
| 决定机位选择 | “压迫” → 低角度；“孤立” → 高角度 + 留白 |
| 决定镜头长度 | “升华” → 给足停留；“推进” → 短促 |
| 决定出图优先级 | 钩子、转折、payoff 必出图 |

## 十、三张锚定串模板

### 风格锚定串

```
[品质锚定：电影级实拍质感/UE5渲染/国漫3D，35mm胶片颗粒，超精细画面]。
[大气声明：每帧都有薄雾弥散，空气中可见尘埃]。
[光影三层：主光来自左侧窗光，光在雾中形成可见光束，面部有柔和阴影]。
[色调系统：冷蓝主调配暖橙实用光，中低饱和，高光克制]。
```

### 角色锚定串

```
[年龄/性别/族裔：35岁东方男性]。
[面部：方脸，眉骨突出，单眼皮细长眼，眼尾下垂，鼻梁挺直，薄唇，肤色偏黄有真实毛孔]。
[发型：黑色短寸，鬓角有白发]。
[服装：深灰棉质圆领T恤，领口松垮，左胸有洗不掉的油渍；外搭藏青工装夹克，袖口磨损]。
[体态：肩宽背厚，站姿略微前倾，右手习惯性插兜]。
```

### 场景锚定串

```
[空间：老式居民楼两居室客厅，层高 2.6 米，墙面有细裂纹]。
[材质：水磨石地面，木质门框掉漆，布艺沙发塌陷]。
[光源：南向窗户自然光，色温 5200K，下午斜射入室]。
[标志物：14 寸显像管电视，折叠饭桌，墙上挂历停在 2003 年]。
[纵深：从门口到窗户约 5 米，中间被饭桌分割成前后两个区域]。
```
