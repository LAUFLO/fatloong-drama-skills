# 生成单元：分镜镜头 → 模型生成的映射

本文件解决一个结构性问题：**分镜镜头不等于生成单元。**

---

## 一、为什么需要这一层

| 维度 | 分镜镜头 | 生成单元 |
|---|---|---|
| 服务对象 | 剪辑 | 模型 |
| 典型时长 | 1–3 秒 | 4–15 秒（2.0）/ 4–30 秒（2.5） |
| 数量 | 多 | 少 |
| 切点 | 精确 | 由模型决定 |

一部 75 秒短片拆出 46 个 1–2 秒的镜头，如果每镜独立生成 4 秒，会产生 184 秒素材，是成片的 2.45 倍，大部分是废镜头。

**正确做法：分镜保持不动，生成层做合并。**

---

## 二、合并规则

### 可以合并

| 条件 | 说明 |
|---|---|
| 同场景、同角色 | 空间和身份连续，模型不容易漂 |
| 连续动作 | 上一镜的动作在下一镜继续 |
| 同机位、同光线 | 不需要重新建立构图 |
| 同段落的快速蒙太奇 | 本来就靠剪辑拼接，合并后一次出 |

### 不能合并

| 情况 | 原因 |
|---|---|
| 跨场景 | 模型会在一次生成里混淆空间 |
| 同一镜头内跨时间 | 时间跳跃需要独立起点 |
| 关键出彩镜 | 需要独立首帧和精确控制 |
| 对白正反打 | 切点必须精确，不能交给模型 |

---

## 三、单元长度

| 模型 | 区间 | 建议 |
|---|---|---|
| 2.0 | 4–15 秒 | 4–7 秒，留剪辑余量 |
| 2.5 | 4–30 秒 | 4–8 秒，30 秒容器只用于长叙事 |

**不要贴着下限做。** 4 秒的单元如果模型只生成 3.8 秒，就没有剪辑余量。

---

## 四、2.0 多镜容器写法

2.0 **不响应时间戳**，只响应镜头序号。

```
@图片1 作为首帧。中景，平视，主角在画面左侧。

镜头1：雨夜全景，主角撑伞从画面左侧走入，镜头缓慢右移。
镜头2：另一把伞的伞面占据画面右侧三分之一，完全虚焦，主角的伞沿在左侧。
镜头3：主角走过霓虹广告牌，背景只有 BeefTV 的色块与光晕。

<电子雨声>，（低频轰鸣）。
全程无字幕。
禁止：任何文字、字幕、LOGO、水印。
```

### 三条纪律

1. 每个镜头都写清“谁、在哪、做什么、镜头怎么动”
2. 不写 `0-2秒` 这类时间码，2.0 不响应
3. 切点不保证均分——三次小样本里，切点都没有按镜头数平均分配

---

## 五、2.5 时间戳容器写法

2.5 支持整数秒时间戳，可以更精确地规划切点。

```
@图片1 作为首帧。

镜头 1 [0:00–0:02]：雨夜全景，主角撑伞从画面左侧走入。
镜头 2 [0:02–0:03.5]：虚焦伞面占据右侧三分之一。
镜头 3 [0:03.5–0:05.5]：主角走过广告牌。

<电子雨声>，（低频轰鸣）。
全程无字幕、无对白文字叠加。
```

### 三条规则

1. 时间段不重叠、不留无意空档
2. 最后一段终点等于总时长
3. 时间戳是预算，不是执行保证

## 六、单元表模板

```markdown
| 单元 | 分镜镜号 | 分镜时长 | 单元时长 | 合并理由 | 首帧 |
|---|---|---|---:|---|---|
| U-01 | 1–3 | 6s | 6s | 同场景加载段 | IMG-001 |
| U-02 | 4–9 | 10s | 5s | 战场连续动作，拆两组 | IMG-004 |
| U-03 | 10–15 | 10s | 5s | 赛博连续动作，拆两组 | IMG-010 |
```

**必须标注首帧来源。** 一个单元只有一个起始帧，不能有两张。

---

## 七、切点风险与对策

| 症状 | 原因 | 对策 |
|---|---|---|
| 切点没按镜头数均分 | 2.0 不响应时间戳 | 接受偏差，后期按实际切点重剪 |
| 少了一个镜头 | 两个镜头被合并成一个 | 减少单次容器内的镜头数，拆成两个单元 |
| 镜头挤在一起 | 单镜描述太短，模型没读懂边界 | 每个镜头写清“谁、在哪、做什么、镜头怎么动” |
| 场景混淆 | 跨场景合并 | 拆单元，跨场景不合并 |
| 首帧对不上 | 单元首帧不是该单元的第一个画面 | 重新指定首帧，或把首帧镜独立成单元 |

**通用原则：一个单元内不超过 4 个分镜镜头。** 超过就拆。

---

## 八、单元内的镜头描述怎么写

1. **锚定串只在单元开头写一次**，不要在镜头 2、3 里重复
2. **每个镜头一句话**，写清主体、动作、机位
3. **动作要有起止**，不要写“他在走动”这种无边界描述
4. **声音统一写在单元末尾**，按镜头顺序排列
5. **负面词只写一次**，放在最末

## 九、完整示例（2.0 多镜容器）

分镜：
- 镜10 雨夜全景，主角左侧边缘
- 镜11 虚焦伞面
- 镜12 撑伞走过广告牌
- 镜13 0.3 秒扫过
- 镜14 回头
- 镜15 雨穿手掌

合并为 U-03（5 秒）与 U-04（5 秒）：

```
【U-03】镜 10–12｜0:00-0:05

@图片1 作为首帧。赛博都市雨夜，青蓝与品红霓虹，粒子雨。

镜头1：全景，主角撑黑伞在画面左侧边缘，身高占画面五分之一，从左侧走入。
镜头2：特写，另一把伞的伞面占右侧三分之一，完全虚焦，左侧是主角的伞沿和半张脸。
镜头3：中景，主角撑伞走过湿漉漉的街道，背景广告牌只有 BeefTV 色块与光晕，右侧是没有脸的行人。

<电子雨声>，（低频轰鸣）。
全程无字幕。
禁止：任何文字、字幕、LOGO、水印。
```

```
【U-04】镜 13–15｜0:05-0:10

@图片1 作为首帧。赛博都市雨夜，主角撑伞在画面左侧。

镜头1：中景，镜头快速横移扫过主角，只停留 0.3 秒，他刚抬手，镜头已经移走。
镜头2：中近景，他回头，视线追着镜头方向，伞微微倾斜，雨落在肩膀上。
镜头3：特写，他伸出手掌接雨，雨滴穿过手掌没有留下水痕，他翻过手背，雨同样穿过。

<电子雨声突然变远>。
全程无字幕。
禁止：任何文字、字幕、LOGO、水印、多余手指。
```

**注意：** 两个单元各有一个 `@图片1`，但它们是两次独立生成，素材编号重新从 1 开始。

- [ ] 是否有跨场景的单元？（有则拆）
- [ ] 单元内镜头数是否超过 4 个？（有则拆）
- [ ] 每个单元是否只有一个首帧？
- [ ] 2.0 单元是否没有写时间戳？
- [ ] 2.5 单元的时间戳是否连续、终点等于总时长？
- [ ] 单元表是否列出了每个单元对应的分镜镜号？
